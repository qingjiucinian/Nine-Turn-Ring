# 九转戒 (JiuZhuan Jie)

Minecraft 1.20.1 Forge 模组，依赖 Curios API。

## 功能

- 进入游戏自动获得【九转戒】
- 永恒绑定诅咒：非创造模式无法拆下、无法丢弃
- 装备到 Curios 戒指栏后激活十转之力：
  - **一转·屠戮**：从第一个箱子开出一转，装备后激活；每击杀1只生物提升5%最终伤害（不装备也可叠层）
  - **二转·辟谷**：时刻饱腹，免疫饥饿、虚弱；获取条件：饥饿死亡1次
  - **三转·洞幽**：持续夜视，免疫黑暗、失明；获取条件：黑暗/低亮度环境死亡3次
  - **四转·生息**：每1秒回4血量（2心），免疫凋零、中毒；获取条件：中毒/凋灵状态死亡4次
  - **五转·凝魄**：每击杀1只生物提升5%最大血量（无上限）；获取条件：击杀凋灵100%掉落
  - **六转·不破**：免疫魔法/药水伤害，50%虚空伤害，75%真实伤害，常驻抗性提升III；获取条件：魔法/虚空/真实伤害死亡3次
  - **七转·涅槃**：死亡时取消死亡，恢复50%最大生命值，10秒无敌，40秒冷却；获取条件：不死图腾效果期间死亡，每次触发图腾叠一层，需3层
  - **八转·天眷**：+100幸运值；获取条件：钓鱼钓到垃圾5次
  - **九转·不灭**：血量最多降至1；获取条件：首次击杀末影龙后必定掉落，悬浮于龙蛋上方三格处
  - **十转·万象**：受击按伤害类型叠加减伤（同类伤害3秒内只能叠一次，每层10%，最高100%），适应三种伤害类型后解锁飞行；持续处于负面效果下会逐渐适应，满5层后完全免疫该负面效果；获取条件：同时装备一—九转+完成所有进度

## 视觉效果

- **物品名称动态配色**：
  - 7~9转：同色系正弦平滑呼吸灯（周期1200ms，放慢呼吸，无生硬跳变）
  - 10转：彩虹逐字流转（250ms/位）+ 整体亮度柔和呼吸（600ms周期，最多60%变白保留彩色底色）
- **Tooltip 副标题动态（全副标题动态）**：
  - 7转「涅槃重生，万劫不灭」：深红→亮红呼吸
  - 8转「鸿运当头，珍宝自来」：深绿→亮绿呼吸
  - 9转「不灭之躯，凡俗难伤」：金色→亮黄呼吸
  - 10转「随境而变，万法归一」：彩虹逐字流转
- 1转、5转 Tooltip 实时显示当前加成数值与累计击杀数
- 7转 Tooltip 实时显示无敌剩余时间 / 冷却剩余时间
- 10转 Tooltip 实时列出各伤害类型适应进度与负面效果适应状态

## 构建

```bash
./gradlew build
```

构建产物在 `build/libs/` 目录。

## 依赖

- Minecraft 1.20.1
- Forge 47.2.0+
- Curios API 1.20.1-5.3.0+

## 开发环境

```bash
./gradlew genIntellijRuns  # IDEA
./gradlew genEclipseRuns   # Eclipse
```
